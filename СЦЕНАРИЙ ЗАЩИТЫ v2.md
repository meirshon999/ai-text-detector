# Сценарий повторной защиты: 3 спикера, 22 слайда, живое демо

> **Презентация:** `reports/Final_Presentation.pptx` (19 основных слайдов + 3 backup).
> **Демо:** двойной щелчок по `Запустить демо.bat` → вкладка **Live: fool the detector**.
> **Время:** ~13 минут доклада + 2–3 минуты демо. Слева — что говорить (English), справа — перевод.
> Наизусть не учить: пересказывать своими словами, числа держать перед глазами.

---

## 0. Где что запускать (сделать ДО защиты)

### Накануне вечером (10 минут)
1. Открыть папку проекта `ai-text-detector`.
2. Двойной щелчок по **`Запустить демо.bat`**. Через 10–20 секунд браузер сам откроет `http://localhost:8501`.
3. Вкладка **Live: fool the detector** → режим **Live (Claude API)** → нажать **Ask Claude**.
   Через ~20 секунд должен появиться ответ и две карточки (старый детектор ~0–5%, новый ~95%+).
   Если ошибка «spending limit» — поднять лимит в console.anthropic.com → Settings → Limits.
4. Переключить на **Offline (saved texts)** → Author = **Mixed: human start + Claude Sonnet 5.5** → **Show answer**.
   Должна появиться цветная подсветка и метка «AI starts here?». Это запасной вариант без интернета.
5. Открыть `reports/Final_Presentation.pptx`, пролистать все слайды.

### За 15 минут до защиты
1. Ноутбук на зарядке, Wi-Fi подключён (для живого режима нужен интернет).
2. Запустить **`Запустить демо.bat`**. Чёрное окно **не закрывать** — это сервер демо.
3. В браузере: вкладка **Live: fool the detector**, режим **Live**, один раз нажать **Ask Claude** («прогрев»: первая загрузка моделей медленная). Потом пролистать страницу наверх.
4. Открыть презентацию в режиме показа (F5). Переключение на демо: **Alt+Tab** в браузер, назад — **Alt+Tab**.
5. Кто ведёт демо: **Спикер 3**. Кто сидит за ноутбуком на слайдах: тот, кто говорит.

### Если что-то пошло не так
| Проблема | Что делать |
|---|---|
| Нет интернета / ошибка API | Переключить режим на **Offline (saved texts)**, сказать: *"No internet here, so we use the texts saved from our experiment — same models, same detectors."* |
| Демо долго грузится | Говорить слайд 15 дальше, потом показать. Не ждать молча. |
| Демо не открывается совсем | Показать слайд 15 — на нём тот же пример. *"Here is the same analysis as a screenshot."* |
| Живой пример дал «неожиданный» результат | *"One example can differ — the averages over 555 questions are on the slides."* Это нормально и честно. |
